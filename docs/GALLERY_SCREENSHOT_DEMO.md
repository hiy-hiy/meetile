# スライド撮影用のGallery

2026年10月31日。ユーザー指定の12枚を使う、ローカル開発版だけの撮影用画面。通常のGalleryとは別の入口を持ち、製品の盤面や保存ルールは変更しない。

## 表示と使い方

- Macへの接続前の画面、接続エラーの画面、またはToday右上の「撮影用ギャラリー」を押す。
- 2026年10月30日〜25日の6作品を新しい順に表示する。撮影用の構成は順に12・9・7・10・8・6ピース。画面には人数・ピース数を表示しない。
- 日付のカード→盤面→写真のタップで詳細を開ける。「一覧へ戻る」→「戻る」で起動画面へ戻る。Todayから開いた場合も、閉じると接続前の画面へ戻る。
- 撮影用画面にはローカル検証の帯と近接診断を表示しない。通常の開発画面では従来どおり表示する。
- Firebaseの起動・接続、認証、カメラでの撮影は不要。DebugのJSと画像の配信にはMetroが必要で、ネットワークを完全に切った状態からの起動を保証するものではない。

## 素材の準備

```sh
pnpm local:gallery-prepare -- /path/to/01.jpg /path/to/02.jpg /path/to/03.jpg /path/to/04.jpg /path/to/05.jpg /path/to/06.jpg /path/to/07.jpg /path/to/08.jpg /path/to/09.jpg /path/to/10.jpg /path/to/11.jpg /path/to/12.jpg
```

JPEG・PNG・WebPの12枚を明示する。写真と番号だけの参照モジュールを`apps/mobile/src/local/gallery-demo/assets.local/`へコピーする。このディレクトリはGit・Lint・フォーマットの対象外。元ファイルの名前やパスは生成モジュールに含めない。素材の準備後にMetroを起動し直す。

```sh
cd apps/mobile
APP_MODE=local APP_ENV=development PROXIMITY_MODE=native pnpm exec expo start --dev-client --port 8086 --lan
```

既存のMetroやローカルサーバーを止めずに、空いている8086で起動できる。端末は表示された開発用URLから読み込む。今回は既存のiPhone Debugアプリを使えるため、ネイティブの作り直しは不要。

素材未準備なら入口を表示しない。削除して使わなくする場合は、コピーされた素材フォルダーだけを取り除いてMetroを起動し直す。`local:reset`は使用しない。

## 実装と境界

- `src/local/gallery-demo/`内に決定的な撮影用盤面・メモリー上の読み取り元・画面を置いた。実GalleryのSQLite、写真キャッシュ、安全ID、サーバーAPIを利用しない。
- 12枚は今回のユーザー指示に基づく撮影専用素材。実写真を自動試験のfixtureや通常版の配布物に使わない。試験には人工素材だけを用いる。
- 連結した固定配置を用意し、隣接する全辺を丸／角と凹凸の両方で噛み合わせる。日ごとに写真の割り当てを変え、一作品内の画像は重複しない。
- 共通の`Gallery`は、読み取り・購読・読み込みの最小インターフェースと、既定値付きの戻るボタン文言を受け取る。通常のGalleryの表示・保存処理は従来どおり。
- Metroのlocal Debug用の解決だけで非公開素材のモジュールを読み込む。通常版の入口にはデモ実装のimportを追加しない。`check:local-boundaries`で両OSの通常版バンドルからlocalモジュールを除外したことを確かめる。
- 撮影用画面を開くと通常の接続画面をアンマウントし、購読やタイマーを停止する。閉じた後は必要に応じて通常のMac接続をやり直す。サーバーや保存済みの本人データを初期化しない。

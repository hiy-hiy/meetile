## 方針：黒地で写真が主役

1回目は方眼ノートを基にした明るい配色にしたが、ユーザーから「配置は見やすいが、BeRealやsetlogのような今っぽくて可愛くてシンプルなものがよい」との指摘を受け、黒地の案を選んでもらって作り直した。配置は1回目を引き継いでいる。

| トークン（`@puzzle-sns/design`の`colors`） | 値                        | 用途                                                          |
| ------------------------------------------ | ------------------------- | ------------------------------------------------------------- |
| `bg`                                       | #000000                   | 画面の地・書き出し画像の地                                    |
| `surface`／`raised`／`pressed`             | #141414／#232323／#323232 | 盤面・カードの面／副ボタン・入力欄／押下時                    |
| `text`／`muted`                            | #FFFFFF／#A3A3A3          | 本文／補足                                                    |
| `cut`                                      | #000000                   | ピースの境目（実物のパズルの切れ目のように見せる）            |
| `dot`                                      | #3A3A3A                   | 盤面のマス角の点（1マス＝`CELL`）                             |
| `blank`                                    | #2B2B2B                   | 無地のピース                                                  |
| `accent`                                   | #FFA8D5                   | 自分のピースの縁取りとFIT中の状態表示だけに使うパステルピンク |
| `danger`                                   | #FF7B7B                   | 取り消せない操作（写真削除・利用終了）                        |
| `caution`／`cautionWash`                   | #FFD27A／#2B2312          | ローカル検証の表示・注意書き                                  |

- 主操作は白いピル型に黒文字、副操作は濃いグレーのピル型にした。角丸は盤面・カード28、写真20、ボタンは完全な丸。
- 文字は、予選前に依存やネイティブの再ビルドを増やさないため、システムの日本語ゴシックの太字を使う。日付は40の極太、曜日は小さなピル型にした（`DayTitle`）。
- `app.config.ts`の`userInterfaceStyle`は`light`のままなので、ステータスバーは両方のレイアウトで明るい文字を指定した。

- PNGは原本のSVGから`sharp`（依存に含まれる版）で生成した。手順：SVGを1024pxで描画して黒で塗りつぶし、アルファを除く。適応アイコンは黒地の矩形を除いた内容を詰めて、半径約305pxの円に収まる大きさで中央に置く。横長ロゴは黒地の矩形を除いて余白を詰め、幅900pxにする。

- Expoの事前生成は`name`から、iOSのPRODUCT_NAME（`Meetile`）とAndroidの`rootProject.name`も更新する。Xcodeのプロジェクト・フォルダ名（`ios/puzzlesns`）は既存のまま残る。
- 画面：ローカル版の接続画面と通常版のオンボーディングの先頭に横長ロゴ（`Wordmark`、幅200）を置いた。読み上げは「Meetile」。同日、ユーザーの依頼でホーム（Today、ローカル版・通常版）の日付の上にも小さなロゴ（幅100・高さ約17）を置いた。盤面は`fill`で残りの高さに合わせて縮むため、盤面とFITを1画面に収める配置は維持される。
